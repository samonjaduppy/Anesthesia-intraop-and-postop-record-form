ขั้นตอนเชื่อมฟอร์มนี้กับ Google Sheet

  1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น Anesthesia_Intraop_Postop_Data
  2. ไปที่เมนู Extensions → Apps Script แล้วลบโค้ดเดิมทั้งหมด วางโค้ดนี้แทน:
  1. กด Deploy → New deployment → เลือกประเภท Web app
  2. ตั้งค่า Execute as: Me และ Who has access: Anyone แล้วกด Deploy
  3. คัดลอก Web app URL ที่ได้
  4. เปิดไฟล์ HTML นี้ด้วยโปรแกรมแก้ไขข้อความ ค้นหา GOOGLE_SCRIPT_URL แล้ววาง URL ที่คัดลอกแทนที่ "PASTE_YOUR_WEB_APP_URL_HERE"
  5. บันทึกไฟล์ แล้วเปิดฟอร์มใหม่อีกครั้ง
  6. ถ้าเคย deploy ไว้แล้วและแค่แก้โค้ด ต้องกด Deploy → Manage deployments → ไอคอนดินสอ → เปลี่ยนเป็น New version → Deploy (URL เดิมยังใช้ได้ ไม่ต้องแก้ไฟล์ HTML ใหม่)

วิธีจับคู่ Intraop กับ Postop เป็นแถวเดียวกัน: ฟอร์มนี้แยกปุ่มบันทึกเป็น 2 ปุ่ม (Intraoperative / Postoperative) โดยใช้ HN + วันที่ผ่าตัด ที่อยู่บนสุดของหน้าเป็นตัวจับคู่ร่วมกัน — กรอกทั้งสองช่องนี้ให้ตรงกันทุกครั้ง แล้วกดปุ่มไหนก็ได้ ระบบจะค้นหาแถวที่มี HN และวันที่ผ่าตัดตรงกันอยู่แล้วใน Sheet แล้วเติมข้อมูลลงคอลัมน์ที่เกี่ยวข้องในแถวนั้นแทนการสร้างแถวใหม่ ถ้ายังไม่มีคู่ HN + วันที่นี้ในชีทมาก่อน ระบบจะสร้างแถวใหม่ให้อัตโนมัติ — ผู้ป่วยที่มาผ่าตัดหลายครั้ง (HN เดิม แต่คนละวัน) จะได้แถวแยกกันอย่างถูกต้อง

ถ้าบันทึกซ้ำด้วย HN + วันที่เดิม: ค่าที่กรอกใหม่จะทับค่าเดิมในคอลัมน์นั้นๆ เสมอ (ถือว่าค่าล่าสุดถูกต้องที่สุด) ยกเว้นถ้าการบันทึกครั้งใหม่ปล่อยช่องไหนว่างไว้ ระบบจะคงค่าเดิมที่เคยกรอกไว้ในชีทไว้ ไม่ลบทิ้ง — ป้องกันกรณีเผลอบันทึกซ้ำแล้วช่องที่เคยกรอกไว้หายไปโดยไม่ตั้งใจ (คอลัมน์ LastUpdated จะอัปเดตทุกครั้งที่มีการบันทึกทับ ใช้เช็คว่าแถวไหนถูกแก้ไขล่าสุดเมื่อไหร่ได้)

หมายเหตุ: เพราะเป็นการส่งข้อมูลแบบ no-cors จึงไม่สามารถอ่านผลลัพธ์ตอบกลับได้โดยตรงจากฟอร์ม — ระบบจะแจ้งว่า "ส่งข้อมูลแล้ว" เมื่อคำขอถูกส่งสำเร็จ แนะนำให้เปิด Google Sheet ทิ้งไว้เพื่อตรวจสอบว่าแถวข้อมูลเข้ามาจริง
